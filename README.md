# Task: Development of Basic E-commerce Components Using Generic Types in TypeScript

## Purpose
- Learn the basics of generic types in TypeScript.
- Develop type-safe functions for data handling.
- Apply generics in a practical example.

## Task Description

Develop basic functions for managing products in an e-commerce store. The system should be able to handle various types of products (electronics, clothing, books).

### Step 1: Creating Product Types

Define a base type for products

Define specific types for each product category

###Step 2: Creating Functions for Product Search
