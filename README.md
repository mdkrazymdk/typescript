# Typescript
## Task: Development of Basic E-commerce Components Using Generic Types in TypeScript

## Purpose
- Learn the basics of generic types in TypeScript.
- Develop type-safe functions for data handling.
- Apply generics in a practical example.

## Task Description

Develop basic functions for managing products in an e-commerce store. The system should be able to handle various types of products (electronics, clothing, books).

### Step 1: Creating Product Types

Define a base type for products

Define specific types for each product category

###Step 2: Creating Functions for Product Search

Define a generic function to find products by ID.

Create a function to filter products by price

###Step 3: Creating a Cart

Define a type for cart items

Write functions for managing the cart

###Step 4: Using the Functions

Create test data for different product types. Demonstrate the functionality of each function. Show how your code handles different product types.

###Requirements

All functions must be type-safe.

Use only functions (no classes).

Add comments to functions.

Validate input data.

###Submission Format
Upload the code to GitHub. In the comments for the task, provide a direct link to the .ts file with the code.
